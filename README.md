# 📦 My AI Box

There are only **2 files** in here. That's on purpose.

| File | What it is |
|---|---|
| **README.md** | This note. It only tells you what to do. |
| **CATALOG.md** | **The list.** Every single thing you collected — 1,110 of them, one per line — plus the notes, the search log and the research, folded in at the bottom. |

## How to use it

1. Open **CATALOG.md**.
2. Press **Ctrl + F**.
3. Type a word, like `mcp` or `model` or `skill`.
4. It jumps to it. Done.

## Line format

```
- name — url
- name — url — note
```

A note rides on the line when there is something worth knowing about the item on
this phone (runs here / does not run here, works / stale / not worth it).

Everything else is at the bottom of the same file, under
**"Notes, search log and research"**:

- **Mobile-useful notes** — what actually answers on this phone (Android 16, Alpine
  aarch64, no gcc, no Docker, terminal-only)
- **Search log** — what the Scout already looked for, so it never searches twice
- **Research** — the six deep dives (`agency-agents`, `anything-awesome`,
  `models-by-capability`, `models-researched-ranked`, `omniroute-origin`,
  `uncensored-models`)

## Why it's like this

Because folders are easy to lose things in. One big list is not.

You don't need to know where anything "belongs". You just search for the word
you want, and it's there. That's the whole system.
