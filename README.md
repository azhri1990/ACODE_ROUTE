# 📦 My AI Box

There are only **2 files** in here. That's on purpose.

| File | What it is |
|---|---|
| **README.md** | This note. It only tells you what to do. |
| **CATALOG.md** | **The list.** Every single thing you collected — 1,107 of them, one per line. |

## How to use it

1. Open **CATALOG.md**.
2. Press **Ctrl + F**.
3. Type a word, like `mcp` or `model` or `skill`.
4. It jumps to it. Done.

## Why it's like this

Because folders are easy to lose things in. One big list is not.

You don't need to know where anything "belongs". You just search for the word
you want, and it's there. That's the whole system.
